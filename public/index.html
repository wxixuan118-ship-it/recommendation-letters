Recommendation letter guide

Choose the right letter of recommendation template

A letter of recommendation template helps users start with the correct structure instead of writing from a blank page. The best template depends on who is writing the letter, who the letter is about, and where it will be submitted. A professor recommendation letter should usually discuss academic performance, research potential, class engagement, writing ability, and readiness for graduate study. A manager recommendation letter should focus on work results, ownership, collaboration, communication, reliability, and measurable impact. A scholarship recommendation letter should connect the applicant's achievements with leadership, service, financial need, long-term goals, or future contribution.

This library includes editable recommendation letter templates for Word-style documents, Google Docs workflows, PDF review, short email recommendations, one-page references, detailed academic letters, employee references, coworker endorsements, internship applications, character references, immigration support letters, and recommendation request letters. Each preview uses replaceable fields such as applicant name, recommender name, program name, company name, deadline, specific achievement, and signature details. Users can preview the sample first, choose the most relevant category, and download a version that can be customized for a real application.
